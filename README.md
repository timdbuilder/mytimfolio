# Timothy's Portfolio

A modern, responsive portfolio website built with Next.js 16, TypeScript, and Tailwind CSS.

## ✨ Features

- 🎨 Modern UI with gradient animations and smooth transitions
- 📱 Fully responsive design
- ⚡ Built with Next.js 16 App Router
- 💎 TypeScript for type safety
- 🎭 Tailwind CSS for styling
- 🚀 Optimized for performance
- 📧 Contact form
- 💼 Project showcase
- 📄 Experience timeline

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/tim_portfolio.git

# Navigate to project directory
cd tim_portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## 📦 Build for Production

```bash
npm run build
npm start
```

## 📝 Customization

Update the following files with your information:

- `/src/components/Hero.tsx` - Name and introduction
- `/src/components/About.tsx` - About section and stats
- `/src/components/Projects.tsx` - Your projects
- `/src/components/Skills.tsx` - Your skills
- `/src/components/Experience.tsx` - Work experience
- `/src/components/Contact.tsx` - Contact information
